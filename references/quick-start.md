# 快速开始：用 AI 帮你写周报

> 两种用法，任选其一。想长期用选「安装」，只想试一下选「直接发」。

---

## 方法一：安装到电脑（推荐，长期用）

对你的 AI 说一句话：

```
帮我安装 hs-weekly-report 这个 skill
```

装完直接说「帮我写周报」就能触发。

**如果 AI 找不到**，用备用方式：Mac 打开「终端」App，粘贴这一行回车：

```bash
curl -fsSL https://raw.githubusercontent.com/handsomeng/hs-weekly-report/main/install.sh | bash
```

其他系统：打开 [GitHub 仓库](https://github.com/handsomeng/hs-weekly-report)，点 `Code` → `Download ZIP`，解压后把文件夹放进你电脑的 skills 目录（WorkBuddy 用户是 `~/.workbuddy/skills/`）。

## 方法二：不安装，直接发给 AI（试一下用这个）

复制下面这段（把"我这周干的事"后面的内容换成你的），发给任意 AI 对话框：

```
你是我的周报助手。我下面写的是这周干的事，请整理成一份能直接发给上级的周报：每个项目写清背景、当前进度（百分比）、本周成果、风险、下周计划、我的思考。信息不够就问我，不要编。别写废话。

我这周干的事：
1. 改了官网首页的图
2. 跟供应商对了一下账
3. 跟进了 A 客户合同
```

发给任意 AI 对话框（豆包 / DeepSeek / 通义 / ChatGPT 等都可以）。AI 会再问你两三个问题（比如"合同卡在哪""下周重点是什么"），你随便答几句，它就给你一份能直接发的周报。

**全程 3 分钟，不用学任何操作。**

---

## 为什么它会这么聪明

因为它背后用的是一套固定的思考框架（详见 `prompt-template.md` 完整版）：

1. 把你写的碎碎念拆成一个个事实
2. 归到对应的项目下面
3. 缺的信息（风险、下周计划、思考）主动问你，不瞎编
4. 最后按"背景 / 进度 / 成果 / 风险 / 下周 / 思考"六个维度组装

你不需要懂这些，AI 会替你完成。

---

## 常见问题

**Q：我写的东西很乱，可以吗？**
可以。越碎越好，想到什么写什么，AI 会帮你整理。

**Q：它问我问题，我不想答怎么办？**
最好答一下，答了周报才真实。如果实在不想答，跟它说"你按常识推断"，它会在对应位置标注出来。

**Q：第一次用和以后每周用有什么区别？**
第一次它会问你手头有哪些项目，你列一次就行。之后每周直接发流水账，它会记住你的项目，越用越快。
